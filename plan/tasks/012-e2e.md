# Task 012 — End-to-End Personal CLI

## Goal
Create one command for the full local workflow.

## Agent prompt
Implement a command conceptually equivalent to:

`music-cli build --project ./projects/demo`

Workflow:
1. load project
2. validate structure
3. analyze missing parts
4. create arrangement
5. generate stems
6. mix
7. repair
8. LoFi
9. master
10. output/master.wav

Requirements:
- clear progress;
- preserve intermediate files;
- exact stage errors;
- `--no-ai` deterministic mode;
- `--dry-run`;
- configurable output directory;
- never overwrite source.

Do not add GUI, cloud, or publishing.

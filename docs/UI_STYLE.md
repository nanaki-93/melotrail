# MeloTrail UI Visual Direction

The visual design should remain dark, but softer than a high-contrast developer dashboard.

Recommended characteristics:

- charcoal / midnight background
- muted blue, teal, lavender and warm amber accents
- avoid neon green as the primary accent
- low-contrast panel borders
- soft shadows
- rounded but not overly playful cards
- music timeline gets most visual emphasis
- warnings use restrained amber/red
- approved state uses muted teal
- locked state uses neutral gray

The UI should feel like a calm creative workstation, not an admin dashboard.

Do not make travel/train visuals part of the core product UI. Those are content topics, not MeloTrail's application identity.

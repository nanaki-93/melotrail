# Quality-pipeline plan index

This directory contains the only active implementation roadmap for Melotrail.
Completed V2 milestone plans, missing prompt manifests, and superseded UI
refactor specifications were removed; Git history remains their archive.

Read in this order:

1. [`PLAN.md`](PLAN.md) — product outcome, current defects, target architecture,
   and delivery phases.
2. [`PROJECT_ANALYSIS.md`](PROJECT_ANALYSIS.md) — file-level root-cause analysis,
   including the current Ensemble Cohesion defects and the five sustain,
   low-end, voice-leading, micro-timing, and delivery-master risks.
3. [`QUALITY_GATES.md`](QUALITY_GATES.md) — code-owned, evidence, listening, and
   release acceptance gates.
4. [`TASKS.md`](TASKS.md) — the complete ordered implementation contract.
5. [`YOUTUBE_READINESS.md`](YOUTUBE_READINESS.md) — platform-policy scope and
   the boundary between release evidence and monetization decisions.
6. [`EXECUTE_ALL_TASKS_PROMPT.md`](EXECUTE_ALL_TASKS_PROMPT.md) — one prompt to
   execute every task in order, validating and committing after each task.
7. [`DOCUMENTATION_AUDIT.md`](DOCUMENTATION_AUDIT.md) — retained, consolidated,
   and removed documentation decisions.

The root [`../../PLAN.md`](../../PLAN.md) is intentionally a short entry point
to this suite. Do not create another active roadmap or a parallel task index.
